SHIELDCODE 2.38 — ЧТО ИЗМЕНИЛОСЬ
===================================

Главное: исправленная копия теперь действительно исправляется, а повторная проверка не возвращает те же замечания.

Почему раньше «исправлялась» одна ошибка из 65:
- Автоисправление умело менять только 4 шаблона. Всё остальное оставалось «вручную».
- Единственная правка (65 → 64) была вредной: сайт заменял yaml.load( внутри текста сообщения и тестовой заготовки.
- Сканер проверял собственные правила, описания, тесты, README и переводы как боевой код и считал их уязвимостями.
- Четыре правила срабатывали даже на собственный рекомендуемый пример исправления.

Что сделано:
- Автоисправление переписано. Теперь исправляются: yaml.load, отключённая проверка TLS (requests, rejectUnauthorized, NODE_TLS_REJECT_UNAUTHORIZED), debug=True в app.run, WTF_CSRF_ENABLED=False, флаги cookie HttpOnly/Secure, tar.extractall (filter='data'), subprocess с shell=True для простых команд, секреты вида PASSWORD = "..." в Python (переносятся в переменные окружения), innerHTML с простым текстом (textContent), target="_blank" (rel), монтирование docker.sock и privileged: true в YAML.
- Правки вносятся только в настоящий код: не внутри строк, комментариев, документации, тестов и описаний правил.
- Если после правки Python-файл перестаёт компилироваться, он возвращается без изменений.
- Всё, что требует решения человека (eval, innerHTML с переменной, SQL, CORS, пути к файлам и т. п.), остаётся в отчёте и не подменяется наугад.
- После исправления сайт заново проверяет копию и сообщает итог: «Исправлено автоматически: N из M. Требуют вашего решения: K».
- Сканер больше не считает находками: документацию (.md, .rst, .txt), файлы переводов, папки tests/fixtures, строки-описания правил и закомментированные строки. Ключи и токены известных форматов по-прежнему ищутся везде.
- Для отдельных строк можно написать комментарий shieldcode: ignore (на этой же строке) или shieldcode: ignore-next-line (на строке выше).
- Уточнены правила: PATH_TRAVERSAL (Path(имя).name — не обращение к файлу), HARDCODED_SECRET_UNQUOTED ('new-password' и autocomplete — не секрет), PY_TAR_EXTRACTALL (с filter= не считается), COOKIE_FLAGS_MISSING (с HttpOnly и Secure не считается), TEMPLATE_UNSAFE_MARKUP (внутри {# #} не считается), GHA_UNTRUSTED_INPUT (передача через env: безопасна), HTTP_URL (адрес с подстановкой {HOST}).
- 8 новых unit-тестов (всего 31). Повторная проверка самого проекта ShieldCode: 0 находок.
- В нижней части сайта отображается версия 2.38.
