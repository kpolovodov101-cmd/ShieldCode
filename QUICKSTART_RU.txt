SHIELDCODE 2.38 — БЫСТРЫЙ ЗАПУСК
================================

MACOS
1. Распакуй ZIP двойным щелчком в Finder.
2. Открой Terminal. Введи cd с пробелом после команды, перетащи папку ShieldCode_v2.38 в окно Terminal и нажми Enter.
3. Проверь Python: python3 --version. Нужна версия 3.10 или новее.
4. Выполни chmod +x run_mac_linux.sh (нужно только при первом запуске), затем ./run_mac_linux.sh.
5. Открой http://127.0.0.1:8765. Не закрывай окно Terminal, пока пользуешься сайтом.

Если рядом находится ShieldCode v2.36 или одна из предыдущих версий, первый запуск перенесёт аккаунты и историю проверок в новую папку. Исходная база останется на месте.

Если увидишь «Address already in use», порт 8765 занят другой копией сервера. Останови её в прежнем окне Terminal сочетанием Control+C и повтори запуск. Если это окно не удаётся найти, используй другой порт: SHIELDCODE_PORT=8776 ./run_mac_linux.sh, затем открой http://127.0.0.1:8776.

LINUX
1. Распакуй ZIP и открой Terminal в папке ShieldCode_v2.38.
2. Убедись, что установлен Python 3.10 или новее.
3. Выполни ./run_mac_linux.sh (если нужно: chmod +x run_mac_linux.sh).
4. Открой http://127.0.0.1:8765.

WINDOWS
1. Установи Python 3.10+ и распакуй ZIP.
2. Запусти run_windows.bat или выполни py server.py.
3. Открой http://127.0.0.1:8765.

На macOS PDF создаёт встроенная служба печати. На Linux для скачивания PDF нужен установленный cupsfilter.

В верхней панели сайта выберите «Русский» или «English». После входа выбор сохраняется в аккаунте и восстанавливается при следующем входе; у гостя — в текущем браузере. Этот язык применяется к интерфейсу и PDF-отчётам.

ИСПОЛЬЗОВАНИЕ
1. Создай аккаунт (логин 3–32 символа: латинские буквы, цифры, точка, дефис или подчёркивание; пароль 10–128 символов). Ошибки теперь показываются прямо под формой. Если логин уже занят, выбери другой или перейди на вкладку «Вход».
2. Загрузи файлы проекта или ZIP-архив и нажми «Запустить проверку». Начни с проблем с критической и высокой важностью.
3. При проверке ShieldCode автоматически сверяет поддерживаемые версии библиотек с онлайн-базой известных уязвимостей. Передаются только названия и версии библиотек, не исходный код.
4. Нажми «Скачать план (PDF)»: документ откроется обычным просмотрщиком PDF. В таблице указано, в каком файле и строке искать проблему, а ниже написано, что делать.
5. «Полный отчёт (PDF)» содержит все проблемы, объяснения, примеры и фрагменты, где скрыты распознанные секреты.
6. Кнопка исправленного проекта скачает один файл в его исходном формате. Если загружен проект или несколько файлов, скачается ZIP. На Mac дважды щёлкни ZIP, чтобы увидеть папку проекта. Исходники, которые ты загрузил, не заменяются.

ПРОВЕРКА ТЕСТОВ (23 unit-теста)
python -m unittest discover -s tests -v

ВАЖНО
- Поддерживаются 157 расширений, 89 специальных имён файлов и 82 правила поиска известных проблем. Проверяются в том числе списки библиотек Bun и Deno; глубина проверки зависит от формата.
- Это бесплатный учебный локальный статический анализатор без платежей и подписки. Он не исполняет загрузки, не сохраняет исходники в истории и маскирует распознанные секреты в snippets.
- Онлайн-проверка библиотек включена автоматически. Передаются только названия и точные версии библиотек, не исходный код. Если интернет-база недоступна, локальная проверка всё равно завершится.
- Если ShieldCode сообщает, что Python не доверяет HTTPS-сертификату базы, выполни в Terminal: `python3 -m pip install --user --upgrade certifi`, затем перезапусти сервер. ShieldCode повторяет временный сетевой запрос и объясняет ошибки сертификата, DNS, тайм-аута и ответа сервера.
- Сканер не гарантирует обнаружение всех уязвимостей. Ноль находок не означает безопасность. Проверяй рекомендации вручную.
- Автоматически исправляются только несколько однозначных шаблонов; остальные проблемы описаны в PDF и требуют ручной проверки.
- ZIP-копия проекта содержит файлы проекта, сохраняет папки и ресурсы, например изображения. Отчёты и другие служебные файлы в проект не добавляются.
- Не публикуй локальный сервер в интернет без HTTPS, защиты production-конфигурации и отдельного аудита.
- Остановка: Ctrl+C.


ЕСЛИ РЕГИСТРАЦИЯ НЕ СРАБАТЫВАЕТ
- Проверь, что окно Терминала с сервером всё ещё открыто.
- Пароль при создании аккаунта должен быть длиной от 10 символов.
- Логин должен содержать 3–32 символа: A–Z, a–z, цифры, точку, дефис или подчёркивание.
- Если увидишь «Такой логин уже занят», переключись на «Вход» или выбери другой логин.
- Если браузер показывает старую версию, останови сервер сочетанием Ctrl+C и запусти run_mac_linux.sh заново.
