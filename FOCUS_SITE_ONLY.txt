ShieldCode — только сайт

В этом архиве нет презентации. Здесь только исходники сайта, сервер, тесты и инструкции.

Быстрый запуск на macOS:
1. Установи Python 3.10+.
2. Открой Terminal в этой папке.
3. Выполни: chmod +x run_mac_linux.sh && ./run_mac_linux.sh
4. Открой: http://127.0.0.1:8765

Для Windows смотри QUICKSTART_RU.txt.
Регистрация: логин 3–32 символа из латинских букв, цифр, точки, дефиса или подчёркивания; пароль 10–128 символов.
После проверки можно скачать PDF-план с таблицей «важность — файл и строка — что сделать» и полный PDF-отчёт с объяснениями и примерами. Один исправленный файл скачивается в исходном формате; проект или несколько файлов — ZIP-архивом с сохранением папок. Исходники пользователя не заменяются, а копия содержит только файлы проекта.

Это локальный учебный статический анализатор, не гарантирующий обнаружение всех уязвимостей. Не публикуй сервер напрямую в интернет без дополнительного аудита и production-защиты.
